# Скрипт-магазин Skystore на Django

Простой и удобный веб-интерфейс для демонстрации, хранения и продажи ваших плагинов, утилит и примеров программного кода. Проект разработан в рамках практического задания по основам веб-разработки на Django.

## 🚀 Реализованный функционал

- **Главная страница (Каталог):** Динамический вывод списка доступных продуктов из базы данных с отображением цен, категорий и изображений. *Реализована постраничная навигация (пагинация) для удобного просмотра больших списков.*
- **Детальная страница товара:** Отдельный контроллер и шаблон для просмотра полной информации о конкретном плагине с возможностью легкого возврата в общий каталог.
- **Страница контактов:** Контактные данные организации, загружаемые динамически из СУБД (Страна, ИНН, адрес компании).
- **Форма обратной связи:** Интерактивная форма (Имя, Телефон, Сообщение). Данные из формы обрабатываются контроллером через POST-запрос, логируются в консоль сервера, а пользователь получает всплывающее Bootstrap-уведомление об успешной отправке.
- **Форма добавления товара:** Страница с валидной HTML-формой, позволяющая пользователям добавлять новые утилиты и программный код в базу данных (включая загрузку изображений) с защитой от ошибок и CSRF-атак.
- **Панель администратора:** Настроен суперпользователь для удобного управления товарами и контентом сайта через встроенную админку Django.
- **Интерфейс:** Вся визуальная часть полностью адаптирована и стилизована с использованием фреймворка **Bootstrap 5**. Код шаблонов декомпозирован: выделен общий базовый шаблон `base.html` и изолированный подшаблон главного меню `menu.html` для устранения дублирования кода.

## 🛠 Технологический стек

- **Python** (версия 3.14+)
- **Django** (встроенный веб-фреймворк)
- **PostgreSQL** (полноценная реляционная СУБД для хранения продуктов и контактов)
- **Pillow** (обработка и валидация загружаемых изображений товаров)
- **python-dotenv** (изоляция конфиденциальных данных и паролей БД в переменных окружения)
- **Bootstrap 5** (современная стилизация макетов)
- **QA Automation:** Black (форматирование), Flake8 (линтер), isort (сортировка импортов) по стандарту **PEP 8**

## 💻 Инструкция по локальному запуску проекта

Для запуска проекта на своем компьютере выполните следующие шаги по порядку:

### 1. Клонирование репозитория
Склонируйте данный проект к себе на компьютер и перейдите в его корневую дирекрию:
```bash
git clone <ссылка_на_ваш_репозиторий>
cd homework_basics_django
```

### 2. Настройка переменных окружения (`.env`)
В корневой директории проекта создайте файл **`.env`** и заполните его своими доступами к локальной базе данных PostgreSQL (файл добавлен в `.gitignore` и не отправляется в публичный репозиторий):
```env
SECRET_KEY=ваша_секретная_строка_django
DB_NAME=my_django_project
DB_USER=postgres
DB_PASSWORD=ваш_пароль_от_postgres
DB_HOST=localhost
DB_PORT=5432
```

### 3. Установка зависимостей и активация окружения
Установите все необходимые библиотеки одной командой:
```bash
pip install -r requirements.txt
```
*(Или `poetry install`, если вы используете менеджер зависимостей Poetry).*

### 4. Применение миграций, загрузка данных и создание администратора
Создайте структуру таблиц в PostgreSQL, загрузите демонстрационные данные из фикстур (при наличии) и создайте учетную запись для входа в панель управления:
```bash
python manage.py migrate
python manage.py loaddata catalog_data.json  # Замените имя файла, если фикстура называется иначе
python manage.py createsuperuser
```

### 5. Запуск сервера разработки
Запустите встроенный локальный сервер Django:
```bash
python manage.py runserver
```

### 6. Проверка в браузере
После успешного запуска перейдите по адресам:
- Главная страница (Каталог): [http://127.0.0](http://127.0.0)
- Раздел «Контакты»: [http://127.0.0contacts/](http://127.0.0contacts/)
- Форма добавления товара: [http://127.0.0product/create/](http://127.0.0product/create/)
- Панель администратора: [http://127.0.0admin/](http://127.0.0admin/)

## 🧹 Проверка качества кода (Linter & Formatting)

Код проекта полностью приведен к стандарту **PEP 8**. Для быстрой автоматической проверки стиля и форматирования в корне проекта настроен конфигурационный файл `pyproject.toml`. 

Вы можете запустить комплексную проверку одной командой:
* **Windows:** Наберите в терминале `.\lint.bat`
* **Mac/Linux:** Наберите в терминале `./lint.sh`

Разработка проекта велась строго по методологии GitFlow:
- Ветка **`main`** — стабильная и защищенная версия проекта.
