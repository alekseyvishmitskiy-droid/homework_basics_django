# Скрипт-магазин Skystore на Django

Простой и удобный веб-интерфейс для демонстрации, хранения и продажи ваших плагинов, утилит и примеров программного кода. Проект разработан в рамках практического задания по основам веб-разработки на Django.

## 🚀 Реализованный функционал

- **Главная страница:** Карточка популярного продукта с ценой и списком преимуществ.
- **Страница контактов:** Контактные данные организации (USA, ИНН, адрес компании).
- **Форма обратной связи:** Интерактивная форма (Имя, Телефон, Сообщение). Данные из формы обрабатываются контроллером, выводятся в консоль сервера, а пользователь получает уведомление об успешной отправке.
- **Интерфейс:** Вся визуальная часть полностью адаптирована и стилизована с использованием фреймворка **Bootstrap 5**.

## 🛠 Технологический стек

## 💻 Инструкция по локальному запуску проекта

Для запуска проекта на своем компьютере выполните следующие шаги по порядку:

### 1. Клонирование репозитория
Склонируйте данный проект к себе на компьютер и перейдите в его корневую директорию:
```bash
git clone <ссылка_на_ваш_репозиторий>
cd homework_basics_django
```

### 2. Установка зависимостей и активация окружения
Проект управляется через **Poetry**. Установите все библиотеки одной командой:
```bash
poetry install
```

### 3. Запуск сервера разработки
Запустите встроенный локальный сервер Django. Если вы работаете на операционной системе Windows, рекомендуется использовать флаг `--noreload` для стабильной работы:
```bash
poetry run python manage.py runserver --noreload
```

### 4. Проверка в браузере
После успешного запуска перейдите по адресам:
- Главная страница: `http://127.0.0`
- Раздел «Контакты»: `http://127.0.0contacts/`
